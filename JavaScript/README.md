
## Included files
- `main.js` — interactive CLI entry point
- `todoListService.js` — task storage, filtering, summaries, and status logic
- `package.json` — script for starting the app

## Run locally
1. Install Node.js if it is not already available on your machine.
2. Open a terminal in this folder.
3. Start the app:
   ```bash
   npm start
   ```
